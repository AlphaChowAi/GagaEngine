# 世界法则（讨论稿）

状态：讨论稿 v0.1。本文所有名称、符号、数值和设定都是**占位提案**，用来引出讨论，随时可以推翻。

## 0. 这份文档是什么

引擎实现的是「这个游戏世界的自然规律」。本文就是这套规律的文字版，它同时是：

- **游戏设定**：这个世界由什么构成，按什么道理运转。
- **内核的输入数据**：引擎代码里不出现「火」「灵能」「铁」这些词，它们全部来自这里。
- **AI 创作的依据**：AI 借用自己已有的科学知识，自创的部分由本文告知。

现实世界是灵感和数据的来源，不是约束。「正确」指在本文的规律之下自洽、守恒、方向一致。

---

## 1. 总则

| 编号 | 法则 | 含义 |
|---|---|---|
| 一 | **守恒** | 各元素的质量、能量（所有形式之和）、动量、电荷，总量不变 |
| 二 | **顺势而流** | 每个领域里，守恒的量自发地从「势」高处流向低处 |
| 三 | **转化须经物质** | 能量只有通过具有相应属性的物质，才能从一种形式变为另一种 |
| 四 | **无特权** | 不论来历，同样的状态有同样的行为。灵能点的火就是火 |
| 五 | **可夸张，不可颠倒** | 快慢和强弱可以为了好玩而调整；方向和账目不可以 |

法则三是这个世界最重要的一条：**没有「法术」这种独立的东西**，只有能让能量变形的物质，以及使用这些物质的生物和器具。

---

## 2. 五个领域

世界上的现象分属五个领域，它们的结构相同：一种守恒的量，被一种「势」推动，
在物质中储存和流动。

| 领域 | 流动的量 | 势 | 储存能力 | 流动能力 |
|---|---|---|---|---|
| 力 | 动量 | 速度 | 质量 | 接触、摩擦 |
| 热 | 热量 | 温度 | 比热 | 导热性 |
| 电 | 电荷 | 电压 | 电容 | 导电性 |
| 质 | 各种物质 | 浓度 | 溶解度 | 扩散性 |
| **灵** | **灵能** | **灵压** | **灵容** | **灵导性** |

前四个借自现实，第五个是这个世界独有的。引擎用同一套传输机制处理它们。

---

## 3. 灵

### 3.1 灵能是什么

灵能是能量的一种形式，与热能、动能、电能、化学能并列，可以互相转化，计入能量总账。

- **灵压**：灵能的「势」，相当于热领域里的温度。灵能从灵压高处流向低处。
- **灵容**：物质储存灵能的能力，相当于比热。
- **灵导性**：物质让灵能通过的能力，相当于导热性或导电性。

### 3.2 灵能从哪里来

1. **灵脉**：地下灵压很高的区域，相当于灵领域的地热。靠近灵脉的岩石、水和植物灵压较高。
2. **生命**：生物把食物里的化学能的一小部分转化为灵能，储存在体内。
3. **含灵物质的反应**：某些物质在燃烧或分解时释放灵能而不是热（见第 6 节）。

### 3.3 灵能到哪里去

**散逸**：不受约束的灵能会逐渐变成热。灵能是「高品质」的能量，变成热很容易，
从热变回灵能则只有生命能做到，而且效率很低。

这解释了两件事：为什么世界没有被灵能填满；为什么灵能是值得争夺和节省的资源。

### 3.4 只有一种灵能【待讨论】

本稿建议灵能只有一种，没有「火属性」「冰属性」之分。属性来自**转化它的物质**：
同样的灵能，流过炎晶变成热，流过浮石变成升力。

好处是规则少、组合多。另一种做法是把灵能分成若干属性，各自守恒，那样更接近传统的元素魔法，
但规则会成倍增加。

## 4. 元素

### 4.1 借自现实的元素

第一批只取十几种常见元素，够用即可：

`H` `C` `N` `O` `Na` `Mg` `Si` `S` `Cl` `Ca` `Fe` `Cu` `Ag` `Au`

它们构成水、空气、木头、岩石、盐、铁、铜、酸、碱等日常物质，性质大体沿用现实。

### 4.2 这个世界独有的元素

符号特意选了现实中不存在的组合，避免混淆。

| 符号 | 暂名 | 特性 | 典型物质 |
|---|---|---|---|
| `Ae` | 灵素 | 灵容极高，是储存灵能的主要元素 | 灵晶：充能后发光，是这个世界的「电池」 |
| `Py` | 炎素 | 灵能流过时转化为热 | 炎晶：通灵即发热，相当于电热丝 |
| `Lm` | 浮素 | 灵能流过时转化为向上的力 | 浮石：通灵即上浮，浮空岛的成因 |
| `Cy` | 寒素 | 用灵能把热量从一侧搬到另一侧 | 霜晶：一面变冷，另一面变热 |
| `Vo` | 雷素 | 灵能与电互相转化 | 雷晶：通灵放电，通电生灵 |

最小可玩集合是 `Ae`、`Py`、`Lm` 三种。`Cy` 和 `Vo` 可以第二批加入。

关于寒素要特别说明：**制冷不是让热量消失**，而是把热量搬走。用霜晶冻住一片水，
抽出来的热会出现在霜晶的另一面。这符合法则一，也是一个可以拿来设计玩法的特性。

## 5. 普通物质的灵属性

法则四要求万物一视同仁，所以每种普通物质也都有灵属性。灵能因此和整个世界发生关系，
而不是只对「魔法物品」起作用。

| 物质 | 灵导性 | 灵容 | 结果 |
|---|---|---|---|
| 银 | 极高 | 低 | 灵能的「导线」 |
| 金 | 高 | 低 | 不易腐蚀的导线 |
| 铜 | 中 | 低 | 便宜的导线，会生锈 |
| 铁 | 几乎为零 | 低 | 隔绝灵能：铁笼、铁甲可以屏蔽灵能 |
| 水 | 中 | 低 | 灵能会沿水扩散，淋湿的东西互相连通 |
| 活的木头 | 沿纹理方向高 | 中 | 树是天然的灵能通道 |
| 岩石 | 低 | 低 | 绝缘 |
| 盐 | 低 | 吸收后迅速散逸为热 | 撒盐可以「泄掉」灵能 |
| 空气 | 很低 | 很低 | 灵能不会自己漏到空气里 |
| 生物组织 | 中 | 中到高 | 生物能储存和引导灵能 |

## 6. 转化

### 6.1 领域之间的转化

每一种转化都要经过相应的物质（法则三），效率都低于 1，损失的部分变成热。

| 从 | 到 | 经由 | 备注 |
|---|---|---|---|
| 灵 | 热 | 炎晶；或任何散逸 | 容易 |
| 热 | 灵 | 仅生命 | 很难，效率很低 |
| 灵 | 力 | 浮石 | 升力大小取决于通过的灵能 |
| 灵 | 电 | 雷晶 | 可逆 |
| 电 | 灵 | 雷晶 | 可逆 |
| 化学 | 灵 | 含灵物质的反应 | 例如燃烧灵草 |
| 灵 | 化学 | 给灵晶充能；推动逆向反应 | 炼金术的基础 |
| 化学 | 热 | 燃烧等 | 同现实 |
| 电 | 热 | 电阻 | 同现实 |
| 力 | 热 | 摩擦、碰撞 | 同现实 |

### 6.2 灵能与化学反应

- **催化**：灵能可以降低反应的门槛，让本来就能发生的反应更容易开始。它不改变反应方向。
- **逆向反应要付出灵能**：把铁锈还原成铁、把水分解，需要投入至少等于该反应所需的能量。
- **反应可以吸收或释放灵能**，就像吸热和放热一样。

### 6.3 反应示例

所有反应都必须配平，包括含自创元素的反应。

```
// 借自现实
C + O2 -> CO2                       放热
2 H2 + O2 -> 2 H2O                  放热
4 Fe + 3 O2 -> 2 Fe2O3              缓慢放热（生锈）
HCl + NaOH -> NaCl + H2O            放热（酸碱中和）

// 这个世界独有
Ae + 2 H2O -> Ae(OH)2 + H2          释放灵能：灵素遇水剧烈反应
2 Lm + O2 -> 2 LmO                  放热：浮石高温氧化，氧化后失去浮力
2 LmO -> 2 Lm + O2                  吸收灵能：逆向反应，可重新炼出浮素
```

第二条的玩法含义：浮空的东西可以被「烧」下来。第三条的含义：有足够灵能就能把它炼回去。

## 7. 生命与角色

角色不是特例，身体是具有以下属性的物质：

- **产生灵能**：把摄入的食物的一部分化学能转为灵能。
- **储存灵能**：身体有灵容，这就是通常所说的「魔力值」。
- **引导灵能**：灵能可以经由身体流向手中的器具或接触的物体。

所谓施法，就是让体内的灵能流过某种转化物质。由此自然得出几条后果：

- **代价由规律算出**：举起越重的东西、冻住越多的水，需要的灵能越多。
- **过度施法会发热**：转化有损耗，损耗变成热，留在施法者和器具上。
- **装备有物理意义**：银制法杖传导好，铁甲会隔绝穿戴者的灵能，湿透的衣服会让灵能外泄。

---

## 8. 一个完整的例子

敌人站在浅水里。

1. 甲用霜晶器具对准水面。灵能从甲的身体流入霜晶，霜晶把水里的热搬到自己的背面。
   水温降到冰点后继续放出潜热，然后结冰。敌人的脚被冻住。甲的器具背面变得很烫。
2. 乙用炎晶器具加热冰面。冰吸热，温度停在冰点直到全部融化。
3. 融水连通了敌人和乙脚下的水洼。乙通过雷晶放电，电沿水传到敌人身上。
   同时，因为水也传导灵能，乙自己的灵能也在沿水外泄。

整个过程里，角色只做了三次「让灵能流过某种晶体」，其余都是规律的推导结果。

双人合作的一种自然设计：两名角色各持不同的转化物质，单独能做的事有限，配合才能形成连锁。

## 9. 这个世界目前没有的东西

以下现象在本稿的法则下不存在。如果游戏需要，应当为它补一条法则，而不是开例外：

- 瞬间移动
- 时间倒流或停止
- 物体变大变小
- 凭空创造或消灭物质
- 起死回生

## 10. 法则如何变成数据（示意）

以下语法仅为示意，用来说明本文的内容最终会写成内核可读的世界定义。

```
domain 灵 {
    quantity:  灵能 (energy)
    potential: 灵压
    storage:   灵容
    transport: 灵导性
    decay:     -> 热
}

element Ae { name: 灵素, molar_mass: 40 g/mol }

substance 炎晶 {
    formula: SiPy2
    convert 灵 -> 热 { efficiency: 0.9 }
}

substance 铁 {
    formula: Fe
    灵导性: 0
}

reaction: 2 Lm + O2 -> 2 LmO { releases: 热 }
```

## 11. 待讨论的问题

1. **灵能是一种还是多种属性？**（第 3.4 节）
2. **世界的风格**：东方、西方，还是架空？这会决定全部名称。本稿的「灵」「晶」只是占位。
3. **自创元素的数量**：三种起步是否够用，五种是否太多。
4. **灵能是否对玩家可见**：显示为数值条，还是只通过发光、发热等现象间接表现。
5. **是否增加「光」和「声」两个领域**：它们对玩法（照明、潜行、共鸣）有用，但会增加规则。
6. **生命的边界**：生物死亡在这套规律里意味着什么，尸体的灵能如何处置。
7. **第 9 节里是否有游戏必需的能力**：如果有，需要为它设计法则。
8. **夸张的尺度**：反应和传导比现实快多少，由哪一层统一控制。
