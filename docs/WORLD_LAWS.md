# 世界法则（讨论稿）

状态：讨论稿 v0.2。标注「已定」的是讨论中明确的决定；其余名称、符号、数值都是**占位提案**。

v0.2 相对 v0.1 的变化：采用七元素（金木水火土冰雷电）；世界分为质、能、界三层；
保留真实化学但只取简单的部分；加入空间与时间法则。

## 0. 这份文档是什么

引擎实现的是「这个游戏世界的自然规律」。本文是这套规律的文字版，它同时是：

- **游戏设定**：这个世界由什么构成，按什么道理运转。
- **内核的输入数据**：引擎代码里不出现「火」「灵能」「铁」这些词，它们全部来自这里。
- **AI 创作的依据**：AI 借用已有的科学知识，自创的部分由本文告知。

现实世界是灵感和数据的来源，不是约束。「正确」指在本文的规律之下自洽、守恒、方向一致。

---

## 1. 世界的三层结构（已定）

```
质：金 木 水 土            构成万物的东西
能：火 冰 雷电，以及灵      万物携带、推动变化的东西
界：空间 时间              万物所在的舞台
```

七元素是玩家认识世界的方式；真实化学是七元素背后的运作机制（见第 4 节）。

---

## 2. 总则

| 编号 | 法则 | 含义 |
|---|---|---|
| 一 | **守恒** | 质的总量、能的总量（所有形式之和）、动量、电荷不变 |
| 二 | **顺势而流** | 能自发地从「势」高处流向低处 |
| 三 | **转化须经物质** | 能只有通过具有相应属性的物质，才能改变形式或作用于界 |
| 四 | **无特权** | 不论来历，同样的状态有同样的行为。灵能点的火就是火 |
| 五 | **界可改，律不改** | 空间和时间的参数可以被局部改变，但上面四条在任何地方都成立 |
| 六 | **可夸张，不可颠倒** | 快慢强弱可以为了好玩而调整；方向和账目不可以 |

法则三意味着：**没有「法术」这种独立的东西**，只有能让能量变形的物质，以及使用它们的生物和器具。

---

## 3. 质：金、木、水、土

四种质是对物质的分类。每种物质属于其中一类，或是几类的混合。

| 质 | 包含什么 | 共同特性 |
|---|---|---|
| **金** | 铁、铜、银、金及合金 | 坚硬、导电、导热、可熔铸 |
| **木** | 木材、草、炭、油、血肉等生命物质 | 可燃、可生长、会腐朽 |
| **水** | 水及水溶液（酸、碱、盐水） | 流动、溶解他物、吸热能力强 |
| **土** | 岩石、沙、矿石、盐、灰烬 | 稳定、不燃、隔热、绝缘 |

**气体**（空气、水汽、燃烧产生的气）不在七元素之内，暂称「气」，视为无形的质。
是否把它提升为一个正式元素（如「风」），见待讨论问题。

## 4. 真实化学：七元素背后的机制（已定：保留，但从简）

### 4.1 范围

- **保留**：十几种真实元素、简单的无机反应、相变。原子在反应中守恒，反应必须配平。
- **不做**：有机化学的反应网络。生命物质作为少数几种「整体物质」处理，每种只有固定的几条反应
  （燃烧、炭化、生长、腐朽）。
- 规模目标：约 30 种物质、约 30 条反应。

第一批真实元素：`H` `C` `N` `O` `Na` `Si` `S` `Cl` `Ca` `Fe` `Cu` `Ag` `Au`

### 4.2 相生：元素之间的转化就是真实的反应（已定：元素可转化，总量守恒）

五行相生不需要另立规则，它们就是真实的化学和物理过程。因为反应是配平的，
质在类别之间转化时总量自然守恒。

| 相生 | 实际过程 | 反应 |
|---|---|---|
| 木生火 | 木材燃烧放热 | `C6H10O5 + 6 O2 -> 6 CO2 + 5 H2O`，放热 |
| 火生土 | 燃烧后留下灰烬 | 木材中含少量矿物质，燃烧后剩下 |
| 土生金 | 矿石冶炼成金属 | `2 Fe2O3 + 3 C -> 4 Fe + 3 CO2`，吸热 |
| 金生水 | 水汽在冰冷的金属上凝结 | 相变（金属导热快，表面最先结露） |
| 水生木 | 植物吸水生长 | `6 CO2 + 5 H2O -> C6H10O5 + 6 O2`，吸收光与灵能 |

### 4.3 相克：由物质属性推导，不需要规定

| 相克 | 原因 |
|---|---|
| 水克火 | 水吸热能力强，蒸发时带走大量热，并隔绝空气 |
| 火克金 | 金属受热软化、熔化 |
| 金克木 | 金属比木硬，可切削 |
| 木克土 | 根系生长撑裂土石 |
| 土克水 | 土能阻挡、吸收水 |

### 4.4 其他保留的反应（示例）

```
2 H2 + O2 -> 2 H2O                  放热（氢气燃爆）
2 H2O -> 2 H2 + O2                  吸收电能（雷电分解水）
4 Fe + 3 O2 -> 2 Fe2O3              缓慢放热（生锈：金归于土）
HCl + NaOH -> NaCl + H2O            放热（酸碱中和）
CaCO3 -> CaO + CO2                  吸热（烧石灰）
Fe + 2 HCl -> FeCl2 + H2            放热（酸蚀金属）
```

一条典型的连锁：雷电击中水面，水分解出氢气和氧气；遇火即燃爆。全程无需专门编写。

### 4.5 嬗变【待讨论】

真实反应保证原子守恒。如果玩法需要更自由的转化（例如直接把石头变成金属），
可以增设一条**嬗变**法则：以灵能为代价，把一种质变成另一种，只保证质的总量守恒。
这条法则是否需要，由玩法决定。

## 5. 能：火、冰、雷电、灵

能的各个领域结构相同：一种守恒的量，被一种「势」推动，在物质中储存和流动。
引擎用同一套传输机制处理它们。

| 元素 | 流动的量 | 势 | 储存能力 | 流动能力 |
|---|---|---|---|---|
| **火** | 热量 | 温度 | 比热 | 导热性 |
| **冰** | 与火同一领域，方向相反 | | | |
| **雷电** | 电荷 | 电压 | 电容 | 导电性 |
| **灵** | 灵能 | 灵压 | 灵容 | 灵导性 |

### 5.1 火与冰

火是加入热量，冰是取走热量，两者共用一本账。冰这种东西是「水加上很少的火」，
水冷到冰点自然结冰，不需要专门的规则。

**制冷不是让热消失，而是把热搬走。** 冻住一片水，被抽出的热会出现在别处。

对玩家而言，火与冰仍是两个独立的元素，对应两种不同的能力。

### 5.2 雷电

电荷从电压高处流向低处。金属和水导电，土和木（干燥时）绝缘。电流通过物体时发热。

### 5.3 灵（已定：保留）

灵能是这个世界独有的能量形式，与热、电并列，计入能量总账。它是角色驱动其他一切的力量。

- **来源**：灵脉（地下灵压很高的区域）；生命（把食物的一部分化学能转为灵能）；
  某些物质反应时释放。
- **去向**：不受约束的灵能逐渐散逸成热。灵能变热容易，热变回灵能只有生命能做到，效率很低。
- **只有一种**：没有属性之分。属性来自转化它的物质。

### 5.4 光

暂不单列。光视为火的一种传播方式（辐射）。是否单列见待讨论问题。

## 6. 转化物质

按法则三，灵能要变成别的东西，必须经过相应的物质。这些是这个世界独有的元素，
符号选用现实中不存在的组合。

| 符号 | 暂名 | 作用 | 对应 |
|---|---|---|---|
| `Ae` | 灵素 | 储存灵能 | 灵（灵晶是这个世界的电池） |
| `Py` | 炎素 | 灵能变为热 | 火 |
| `Cy` | 寒素 | 用灵能把热从一侧搬到另一侧 | 冰 |
| `Vo` | 雷素 | 灵能与电互相转化 | 雷电 |
| `Xu` | 空素 | 用灵能改变空间的参数 | 空间 |
| `Zh` | 时素 | 用灵能改变时间的流速 | 时间 |

所有转化的效率都低于 1，损失的部分变成热。

金、木、水、土是质，操纵它们的方式是对它们施力或推动反应，
具体由哪些物质承担见待讨论问题。

---

## 7. 普通物质的灵属性

按法则四，每种普通物质也都有灵属性，灵能因此与整个世界发生关系。

| 物质 | 灵导性 | 结果 |
|---|---|---|
| 银 | 极高 | 灵能的「导线」 |
| 金 | 高 | 不易腐蚀的导线 |
| 铜 | 中 | 便宜的导线，会生锈 |
| 铁 | 几乎为零 | 隔绝灵能：铁笼、铁甲可以屏蔽灵能 |
| 水 | 中 | 灵能沿水扩散，淋湿的东西互相连通 |
| 活的木 | 沿纹理方向高 | 树是天然的灵能通道 |
| 岩石 | 低 | 绝缘 |
| 盐 | 吸收后迅速散逸为热 | 撒盐可以「泄掉」灵能 |
| 空气 | 很低 | 灵能不会自己漏到空气里 |
| 生物组织 | 中，且灵容高 | 生物能储存和引导灵能 |

## 8. 界：空间与时间（已定：两类能力都要）

空间和时间不是元素，是万物所在的舞台。操纵它们就是**局部修改舞台的参数**。
按法则五，参数变了，规律不变；按法则三，修改须经空素或时素，并消耗灵能。

### 8.1 时间

每个物体或区域有一个**时率**，正常为 1。

| 能力 | 做法 | 规则 |
|---|---|---|
| 减速、加速 | 时率改为小于或大于 1 | 该物体的一切过程（运动、燃烧、传热）同比变慢或变快 |
| 静止 | 时率为 0 | 物体不响应，但受到的力和热不会丢失，累积到解除时一并生效 |
| 整体回溯 | 整个世界回到过去某一刻 | 世界连同全部账目一起回退，守恒自然成立 |
| 局部回溯 | 单个物体回到过去的状态 | 恢复位置、运动、形状、温度；差额以灵能支付 |

- **代价**：维持时率差持续消耗灵能。物体越大、时率偏离越多、时间越久，消耗越大。
- **边界**：时率不同的物体之间交换的量，双方必须相等。
- **局部回溯的限制**【待讨论】：已经离开物体的质（例如烧掉后散走的气）不能凭空找回。
  烧成灰的木头不能靠局部回溯复原，除非那些质还在附近。

### 8.2 空间

| 能力 | 做法 | 规则 |
|---|---|---|
| 传送门 | 让两处变成相邻 | 一切都能通过：物体、水、热、电、灵能，不只是角色 |
| 重力改变 | 局部改变重力的方向和强弱 | 重力视为空间的属性 |
| 缩放 | 改变一个区域的尺度 | 质量不变，因此密度随之变化 |
| 储物空间 | 一个独立的小世界 | 其中的时率可以另设（例如静止以保鲜） |

- **传送门与能量**：物体穿过传送门到达更高处，增加的势能由灵能支付。否则可以造出永动机。
- **动量**：穿过传送门时，运动方向随门的朝向转动，大小不变。
- **代价**：维持传送门、重力偏离和缩放都持续消耗灵能。

## 9. 生命与角色

角色不是特例，身体是具有以下属性的物质（属于木）：

- **产生灵能**：把摄入食物的一部分化学能转为灵能。
- **储存灵能**：身体有灵容，这就是通常所说的「魔力值」。
- **引导灵能**：灵能可以经由身体流向手中的器具或接触的物体。

所谓施法，就是让体内的灵能流过某种转化物质。由此自然得出：

- **代价由规律算出**：举起越重的东西、冻住越多的水，需要的灵能越多。
- **过度施法会发热**：转化的损耗变成热，留在施法者和器具上。
- **装备有物理意义**：银制法杖传导好；铁甲隔绝穿戴者的灵能；湿透的衣服让灵能外泄。

## 10. 一个完整的例子

敌人站在浅水里，背后是一堵石墙。

1. 甲用寒素器具对准水面。灵能流入寒素，把水里的热搬到器具背面。水结冰，敌人的脚被冻住，
   甲的器具背面变得很烫。
2. 乙用时素器具让敌人所在的区域减速。敌人挣脱冰的动作变慢，冰融化的速度也同样变慢。
3. 甲在石墙上开一道传送门，另一头连到高处的水池。水穿过门涌出，同时水池一侧的寒气也透了过来。
4. 乙用雷素器具向水放电。电沿水传到敌人身上。因为水也传导灵能，乙自己的灵能也在外泄。

角色只做了四次「让灵能流过某种物质」，其余都是规律的推导结果。

双人合作的一种自然设计：两名角色各持不同的转化物质，单独能做的事有限，配合才能形成连锁。

## 12. 法则如何变成数据（示意）

以下语法仅为示意，说明本文的内容最终会写成内核可读的世界定义。

```
domain 灵 {
    quantity:  灵能 (energy)
    potential: 灵压
    storage:   灵容
    transport: 灵导性
    decay:     -> 火
}

substance 铁 {
    formula: Fe
    class:   金
    灵导性:  0
}

substance 木材 {
    formula: C6H10O5        // 整体物质，不展开有机反应
    class:   木
}

reaction 燃烧: C6H10O5 + 6 O2 -> 6 CO2 + 5 H2O { releases: 火 }

converter 寒素 { 灵 drives 火: from side_a to side_b }
converter 时素 { 灵 sets 时率 }
```

## 13. 对引擎的要求（由本文法则引出）

这些需要在引擎设计之初就考虑，后加的代价很高：

1. **每个物体有自己的时率**：模拟推进时各物体的时间步长可以不同。
2. **确定性与快照**：整体回溯要求模拟可重现，并能保存和恢复完整的世界状态。
3. **传送门**：渲染要能透过门看到另一侧；物理要处理跨门的接触、流动和传导。
4. **多个世界并存**：储物空间是独立的小世界，需要同时模拟或冻结。
5. **重力是局部的场**，不是全局常数。

## 14. 待讨论的问题

1. **气的地位**：气体不在七元素之内。保持为无名的「气」，还是增设一个元素（如「风」）？
2. **如何操纵金、木、水、土**：火、冰、雷电各有对应的转化物质，四种质由什么来操纵？
   例如用雷电产生的磁力操纵金，用灵能催化生长来操纵木。
3. **是否需要嬗变**（第 4.5 节）。
4. **局部回溯的限制是否合适**（第 8.1 节）。
5. **光和声是否单列为领域**：对照明、潜行、共鸣等玩法有用，但会增加规则。
6. **灵能是否对玩家可见**：显示为数值条，还是只通过发光、发热等现象间接表现。
7. **生命的边界**：死亡在这套规律里意味着什么，尸体的灵能如何处置。
8. **命名与风格**：本稿的名称都是占位，需按最终的世界观统一。
9. **夸张的尺度**：反应和传导比现实快多少，由哪一层统一控制。
