# 世界法则（讨论稿）

状态：讨论稿 v0.3。标注「已定」的是讨论中明确的决定；其余名称、符号、数值都是**占位提案**。

v0.3 相对 v0.2 的变化：气升为正式元素，共八元素；确立八元素的大循环，冰为单向支脉；
加入操控提案（一种灵晶，多种相）。

## 0. 这份文档是什么

引擎实现的是「这个游戏世界的自然规律」。本文是这套规律的文字版，它同时是：

- **游戏设定**：这个世界由什么构成，按什么道理运转。
- **内核的输入数据**：引擎代码里不出现「火」「灵能」「铁」这些词，它们全部来自这里。
- **AI 创作的依据**：AI 借用已有的科学知识，自创的部分由本文告知。

现实世界是灵感和数据的来源，不是约束。「正确」指在本文的规律之下自洽、守恒、方向一致。

## 1. 世界的三层结构（已定）

```
质：金 木 水 土 气         构成万物的东西
能：火 雷电，以及灵         万物携带、推动变化的东西
冰：水失去火之后的形态，兼有质与能两面
界：空间 时间               万物所在的舞台
```

八元素是玩家认识世界的方式；真实化学是八元素背后的运作机制（见第 4 节）。

---

## 2. 总则

| 编号 | 法则 | 含义 |
|---|---|---|
| 一 | **守恒** | 质的总量、能的总量（所有形式之和）、动量、电荷不变 |
| 二 | **顺势而流** | 能自发地从「势」高处流向低处 |
| 三 | **转化须经物质** | 能只有通过具有相应属性的物质，才能改变形式或作用于界 |
| 四 | **无特权** | 不论来历，同样的状态有同样的行为。灵能点的火就是火 |
| 五 | **界可改，律不改** | 空间和时间的参数可以被局部改变，但上面四条在任何地方都成立 |
| 六 | **可夸张，不可颠倒** | 快慢强弱可以为了好玩而调整；方向和账目不可以 |

法则三意味着：**没有「法术」这种独立的东西**，只有能让能量变形的物质，以及使用它们的生物和器具。

## 3. 质：金、木、水、土、气，以及冰

质是对物质的分类。每种物质按它当前的形态属于其中一类，或是几类的混合。

| 质 | 包含什么 | 共同特性 |
|---|---|---|
| **金** | 铁、铜、银、金及合金 | 坚硬、导电、导热、可熔铸 |
| **木** | 木材、草、炭、油、血肉等生命物质 | 可燃、可生长、会腐朽 |
| **水** | 液态的水及水溶液（酸、碱、盐水） | 流动、溶解他物、吸热能力强 |
| **土** | 岩石、沙、矿石、盐、灰烬 | 稳定、不燃、隔热、绝缘 |
| **气**（已定：正式元素） | 空气、水汽、氢气、燃烧产生的气 | 无形、可压缩、助燃或窒息、承载风 |
| **冰** | 凝固的水 | 坚硬而脆，是水失去热之后的形态 |

同一种物质会随形态改变归属：液态是水，凝固是冰，蒸发是气。

## 4. 真实化学：八元素背后的机制（已定：保留，但从简）

### 4.1 范围

- **保留**：十几种真实元素、简单的无机反应、相变。原子在反应中守恒，反应必须配平。
- **不做**：有机化学的反应网络。生命物质作为少数几种「整体物质」处理，每种只有固定的几条反应
  （燃烧、炭化、生长、腐朽）。
- 规模目标：约 30 种物质、约 30 条反应。

第一批真实元素：`H` `C` `N` `O` `Na` `Si` `S` `Cl` `Ca` `Fe` `Cu` `Ag` `Au`

### 4.2 大循环：八元素的相生（已定：元素可转化，总量守恒）

主环由七个元素首尾相接，冰是从水分出的单向支脉。

```
木 → 火 → 土 → 金 → 水 → 气 → 雷电 → 木
                     │
                     └→ 冰
```

相生不需要另立规则，每一环都是真实的化学或物理过程。因为反应是配平的，
质在类别之间转化时总量自然守恒。

| 相生 | 实际过程 | 反应 |
|---|---|---|
| 木生火 | 木材燃烧放热 | `C6H10O5 + 6 O2 -> 6 CO2 + 5 H2O`，放热 |
| 火生土 | 燃烧后留下灰烬 | 木材中含少量矿物质，燃烧后剩下 |
| 土生金 | 矿石冶炼成金属 | `2 Fe2O3 + 3 C -> 4 Fe + 3 CO2`，吸热 |
| 金生水 | 水汽在冰冷的金属上凝结 | 相变（金属导热快，表面最先结露） |
| 水生气 | 水受热蒸发 | 相变，吸热 |
| 气生雷电 | 气流中的水滴与冰粒摩擦，分离电荷，积累成雷电 | 电荷分离 |
| 雷电生木 | 雷电使气中的氮与氧结合，随雨入土成为养分，草木生长 | `N2 + O2 -> 2 NO`，吸收电能 |
| 水生冰（支脉） | 水失热凝固 | 相变，放热 |

关于单向：这里的方向指**相生关系**。冰由水而生，但冰不再生出其他元素，是循环的终点之一。
冰受热仍会融化成水，这属于物态变化，不算「冰生水」。【理解是否正确，见待讨论问题】

草木生长仍然需要水（`6 CO2 + 5 H2O -> C6H10O5 + 6 O2`，吸收光与灵能），
这是生长的物质来源，但不作为大循环的一环。

### 4.3 相克与相助：由物质属性推导，不需要规定

| 关系 | 原因 |
|---|---|
| 水克火 | 水吸热能力强，蒸发时带走大量热，并隔绝气 |
| 火克金 | 金属受热软化、熔化 |
| 金克木 | 金属比木硬，可切削 |
| 木克土 | 根系生长撑裂土石 |
| 土克水 | 土能阻挡、吸收水 |
| 火克冰 | 冰吸热融化 |
| 冰克木 | 草木受冻枯死 |
| 冰克水 | 冻结使水不能流动 |
| 气助火 | 燃烧需要气中的氧；断气则火灭 |
| 金引雷电 | 金属导电，把雷电引走 |
| 土克雷电 | 土绝缘，并能把电荷导入大地消散 |
| 雷电克水 | 电使水分解为两种气 |

### 4.4 其他保留的反应（示例）

```
2 H2 + O2 -> 2 H2O                  放热（氢气燃爆）
2 H2O -> 2 H2 + O2                  吸收电能（雷电分解水）
4 Fe + 3 O2 -> 2 Fe2O3              缓慢放热（生锈：金归于土）
HCl + NaOH -> NaCl + H2O            放热（酸碱中和）
CaCO3 -> CaO + CO2                  吸热（烧石灰）
Fe + 2 HCl -> FeCl2 + H2            放热（酸蚀金属）
```

一条典型的连锁：雷电击中水面，水分解出氢气和氧气；遇火即燃爆。全程无需专门编写。

### 4.5 嬗变【待讨论】

真实反应保证原子守恒。如果玩法需要更自由的转化（例如直接把石头变成金属），
可以增设一条**嬗变**法则：以灵能为代价，把一种质变成另一种，只保证质的总量守恒。
这条法则是否需要，由玩法决定。

## 5. 能：火、冰、雷电、灵

能的各个领域结构相同：一种守恒的量，被一种「势」推动，在物质中储存和流动。
引擎用同一套传输机制处理它们。

| 元素 | 流动的量 | 势 | 储存能力 | 流动能力 |
|---|---|---|---|---|
| **火** | 热量 | 温度 | 比热 | 导热性 |
| **冰** | 与火同一领域，方向相反（冰同时也是一种质，见第 3 节） | | | |
| **雷电** | 电荷 | 电压 | 电容 | 导电性 |
| **灵** | 灵能 | 灵压 | 灵容 | 灵导性 |

### 5.1 火与冰

火是加入热量，冰是取走热量，两者共用一本账。冰这种东西是「水加上很少的火」，
水冷到冰点自然结冰，不需要专门的规则。

**制冷不是让热消失，而是把热搬走。** 冻住一片水，被抽出的热会出现在别处。

对玩家而言，火与冰仍是两个独立的元素，对应两种不同的能力。

### 5.2 雷电

电荷从电压高处流向低处。金属和水导电，土和木（干燥时）绝缘。电流通过物体时发热。

### 5.3 灵（已定：保留）

灵能是这个世界独有的能量形式，与热、电并列，计入能量总账。它是角色驱动其他一切的力量。

- **来源**：灵脉（地下灵压很高的区域）；生命（把食物的一部分化学能转为灵能）；
  某些物质反应时释放。
- **去向**：不受约束的灵能逐渐散逸成热。灵能变热容易，热变回灵能只有生命能做到，效率很低。
- **只有一种**：没有属性之分。属性来自转化它的物质。

### 5.4 光

暂不单列。光视为火的一种传播方式（辐射）。是否单列见待讨论问题。

## 6. 操控（提案）

### 6.1 原则

1. **操控不创造。** 只能搬运和转化已经存在的东西。筑起一道土墙，原地就留下一个坑；
   沙漠里没有水，就没有水可用，除非自己带着。
2. **一种灵晶，多种相。** 这个世界独有的元素只有一种：灵素（`Ae`），它的晶体叫灵晶，
   能储存灵能。灵晶长期处在某种元素之中，会染上该元素的**相**，成为相晶。
   相晶只对自己那一种元素起作用。
3. **两种作用方式。** 对质是**牵引**：一种有选择的力，像磁铁只吸铁一样，只作用于对应的那类物质。
   对能是**转换**：把灵能变成那种能，或反过来。
4. **代价由规律算出。** 牵引的代价是所做的功，转换的代价是转换的能量，再除以效率；
   损耗变成热。作用随距离衰减，直接接触最省灵能。

### 6.2 相晶的来历

| 相晶 | 如何形成 |
|---|---|
| 炎晶 | 灵晶久置火中 |
| 霜晶 | 灵晶久封冰中 |
| 雷晶 | 灵晶遭雷击 |
| 金晶 | 灵晶生于金属矿脉 |
| 木晶 | 灵晶被活树包裹生长 |
| 澜晶 | 灵晶久沉水底 |
| 岩晶 | 灵晶深埋土石 |
| 风晶 | 灵晶久悬高空 |
| 空晶、时晶 | 只在特殊的地方形成，稀有（见第 8 节） |

相晶因此可以由玩家亲手制作，制作过程本身就用到这个世界的规律。

### 6.3 各元素的操控

| 元素 | 相晶 | 作用 | 能做的事 | 取材与限制 |
|---|---|---|---|---|
| 金 | 金晶 | 牵引金属 | 隔空移动、投掷金属；金属烧软后可弯折塑形 | 须有金属在场；越重越费灵能 |
| 木 | 木晶 | 牵引草木；催生 | 让藤蔓生长成桥、让根系撑裂土石 | 生长要消耗水和气，无水不长；死木只能牵引，不能生长 |
| 水 | 澜晶 | 牵引水 | 引流、托起水球、分开水面 | 须有水源；水量不变 |
| 火 | 炎晶 | 灵能变为热 | 加热、引燃、熔化 | 没有可燃物，火不能持久；晶体自身也发热 |
| 土 | 岩晶 | 牵引土石 | 筑墙、掘坑、投石 | 墙从地里来，原处留坑 |
| 冰 | 霜晶 | 搬运热；牵引冰 | 冻结水面、造冰桥、移动冰块 | 须有水；抽出的热出现在晶体另一侧 |
| 雷电 | 雷晶 | 灵能与电互转 | 放电、给器物通电、借电生磁 | 电走最容易的路，没有导体引导就会乱窜，包括窜向自己 |
| 气 | 风晶 | 牵引气 | 造风、加压、抽空；助燃或断气灭火；托举轻物 | 气处处都有，但很轻，力道小 |
| 空间 | 空晶 | 改变空间参数 | 传送门、改变重力、缩放、储物 | 见第 8 节 |
| 时间 | 时晶 | 改变时率 | 减速、加速、静止、回溯 | 见第 8 节 |

### 6.4 组合举例

组合不需要专门编写，都是规律的结果：

- 风 + 火：送气使火势大涨；抽气使火熄灭。
- 岩 + 澜：土与水混合成泥沼，困住敌人。
- 澜 + 雷：水分解成两种气，遇火燃爆。
- 霜 + 风：把冷气吹向远处，大范围降温。
- 木 + 岩：催生根系撑裂石墙。
- 金 + 雷：通电的金属产生磁力，更省力地牵引其他金属。
- 炎 + 金：先烧软，再塑形。

## 7. 普通物质的灵属性

按法则四，每种普通物质也都有灵属性，灵能因此与整个世界发生关系。

| 物质 | 灵导性 | 结果 |
|---|---|---|
| 银 | 极高 | 灵能的「导线」 |
| 金 | 高 | 不易腐蚀的导线 |
| 铜 | 中 | 便宜的导线，会生锈 |
| 铁 | 几乎为零 | 隔绝灵能：铁笼、铁甲可以屏蔽灵能 |
| 水 | 中 | 灵能沿水扩散，淋湿的东西互相连通 |
| 活的木 | 沿纹理方向高 | 树是天然的灵能通道 |
| 岩石 | 低 | 绝缘 |
| 盐 | 吸收后迅速散逸为热 | 撒盐可以「泄掉」灵能 |
| 空气 | 很低 | 灵能不会自己漏到空气里 |
| 生物组织 | 中，且灵容高 | 生物能储存和引导灵能 |

## 8. 界：空间与时间（已定：两类能力都要）

空间和时间不是元素，是万物所在的舞台。操纵它们就是**局部修改舞台的参数**。
按法则五，参数变了，规律不变；按法则三，修改须经空晶或时晶，并消耗灵能。

### 8.1 时间

每个物体或区域有一个**时率**，正常为 1。

| 能力 | 做法 | 规则 |
|---|---|---|
| 减速、加速 | 时率改为小于或大于 1 | 该物体的一切过程（运动、燃烧、传热）同比变慢或变快 |
| 静止 | 时率为 0 | 物体不响应，但受到的力和热不会丢失，累积到解除时一并生效 |
| 整体回溯 | 整个世界回到过去某一刻 | 世界连同全部账目一起回退，守恒自然成立 |
| 局部回溯 | 单个物体回到过去的状态 | 恢复位置、运动、形状、温度；差额以灵能支付 |

- **代价**：维持时率差持续消耗灵能。物体越大、时率偏离越多、时间越久，消耗越大。
- **边界**：时率不同的物体之间交换的量，双方必须相等。
- **局部回溯的限制**【待讨论】：已经离开物体的质（例如烧掉后散走的气）不能凭空找回。
  烧成灰的木头不能靠局部回溯复原，除非那些质还在附近。

### 8.2 空间

| 能力 | 做法 | 规则 |
|---|---|---|
| 传送门 | 让两处变成相邻 | 一切都能通过：物体、水、热、电、灵能，不只是角色 |
| 重力改变 | 局部改变重力的方向和强弱 | 重力视为空间的属性 |
| 缩放 | 改变一个区域的尺度 | 质量不变，因此密度随之变化 |
| 储物空间 | 一个独立的小世界 | 其中的时率可以另设（例如静止以保鲜） |

- **传送门与能量**：物体穿过传送门到达更高处，增加的势能由灵能支付。否则可以造出永动机。
- **动量**：穿过传送门时，运动方向随门的朝向转动，大小不变。
- **代价**：维持传送门、重力偏离和缩放都持续消耗灵能。

## 9. 生命与角色

角色不是特例，身体是具有以下属性的物质（属于木）：

- **产生灵能**：把摄入食物的一部分化学能转为灵能。
- **储存灵能**：身体有灵容，这就是通常所说的「魔力值」。
- **引导灵能**：灵能可以经由身体流向手中的器具或接触的物体。

所谓施法，就是让体内的灵能流过某种转化物质。由此自然得出：

- **代价由规律算出**：举起越重的东西、冻住越多的水，需要的灵能越多。
- **过度施法会发热**：转化的损耗变成热，留在施法者和器具上。
- **装备有物理意义**：银制法杖传导好；铁甲隔绝穿戴者的灵能；湿透的衣服让灵能外泄。

## 10. 一个完整的例子

敌人站在浅水里，背后是一堵石墙。

1. 甲用霜晶器具对准水面。灵能流入霜晶，把水里的热搬到器具背面。水结冰，敌人的脚被冻住，
   甲的器具背面变得很烫。
2. 乙用时晶器具让敌人所在的区域减速。敌人挣脱冰的动作变慢，冰融化的速度也同样变慢。
3. 甲用空晶器具在石墙上开一道传送门，另一头连到高处的水池。水穿过门涌出，同时水池一侧的寒气也透了过来。
4. 乙用雷晶器具向水放电。电沿水传到敌人身上。因为水也传导灵能，乙自己的灵能也在外泄。

角色只做了四次「让灵能流过某种物质」，其余都是规律的推导结果。

双人合作的一种自然设计：两名角色各持不同的转化物质，单独能做的事有限，配合才能形成连锁。

- 读心、控制他人

## 13. 对引擎的要求（由本文法则引出）

这些需要在引擎设计之初就考虑，后加的代价很高：

1. **每个物体有自己的时率**：模拟推进时各物体的时间步长可以不同。
2. **确定性与快照**：整体回溯要求模拟可重现，并能保存和恢复完整的世界状态。
3. **传送门**：渲染要能透过门看到另一侧；物理要处理跨门的接触、流动和传导。
4. **多个世界并存**：储物空间是独立的小世界，需要同时模拟或冻结。
5. **重力是局部的场**，不是全局常数。

## 14. 待讨论的问题

1. **对「单向」的理解是否正确**（第 4.2 节）：本稿理解为相生关系上的单向，
   即冰由水而生、不再生出其他元素，但冰受热仍会融化。除了水与冰，还有哪些关系应当是单向的？
2. **大循环的顺序是否合适**：木、火、土、金、水、气、雷电。传统的「水生木」被「雷电生木」取代，
   水改为生气。
3. **「一种灵晶，多种相」是否合适**：好处是自创元素只有一种、相晶可以制作；
   另一种做法是每个元素有各自独立的自创元素。
4. **双人如何分配相晶**：例如各持四种，或自由更换。
5. **是否需要嬗变**（第 4.5 节）。
6. **局部回溯的限制是否合适**（第 8.1 节）。
7. **光和声是否单列为领域**：对照明、潜行、共鸣等玩法有用，但会增加规则。
8. **灵能是否对玩家可见**：显示为数值条，还是只通过发光、发热等现象间接表现。
9. **生命的边界**：死亡在这套规律里意味着什么，尸体的灵能如何处置。
10. **命名与风格**：本稿的名称都是占位，需按最终的世界观统一。
11. **夸张的尺度**：反应和传导比现实快多少，由哪一层统一控制。
